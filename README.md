# WordWiz

WordWiz 是一个基于 C++ 和 WinUI 3 开发的现代 Windows 桌面应用，致力于为用户提供优雅、高效的词汇管理体验。

本项目是来自西南交通大学 计算机与人工智能学院 同学们的C++课程设计。

目前该项目的各项功能还不完善，以及我们都还在学习中，很多代码写的不是很好，含有有AI生成的代码。

## 安装方法

### 1. 使用预发布安装包（推荐）

1. 前往 [Releases](https://github.com/WangJunwei233/WordWiz/releases) 页面，下载最新的 `pre_release` 安装包（如 `.msix` 或 `.msixbundle`）。
2. 按提示完成安装。
3. **首次启动前**，请务必将 `words.sqlite` 数据库文件手动复制到应用的数据文件夹（可在**设置 → 通用**内查看具体路径）。
   - 未放置数据库文件将导致应用无法正常加载词库。
4. 启动应用，按需配置和使用。

### 2. 本地编译

#### 环境要求

- **操作系统**：Windows 11
- **开发环境**：Visual Studio 2022（建议使用最新版）
- **组件要求**：首次打开时Visual Studio会自动安装。记得点 还原NuGet包 安装所需要的第三方库

#### 编译步骤

1. 克隆仓库
2. 用 Visual Studio 2022 打开 `.sln` 解决方案文件。
3. 还原 NuGet 包（首次打开会自动提示）。
4. 选择 `Release` 或 `Debug` 模式。
5. 构建项目。
6. 在输出目录下找到生成的可执行文件。
7. **务必将 `words.sqlite` 拷贝到应用的数据文件夹**（可在“设置 → 通用”内找到路径）。

#### 注意事项

- **系统须为 Windows 11**
- 若缺少依赖或遇到编译报错，请检查 Windows App SDK 及相关 UWP 组件是否完整。
- 数据库文件缺失将导致应用无法正常使用。
- 刚打开项目一堆错误是正常的，在已经还原NuGet包后尝试全部重新构建，因为该框架依赖于XAML编译器自动生成的C++代码，所以如果项目没有编译过IntelliCode会找不到那些文件。
